# Pasta PROJETOS

Guarde aqui os arquivos originais dos seus projetos (PSD, AI, INDD, PDFs,
fotos em alta, etc.). Nada nesta pasta aparece no site.

Para um projeto aparecer no portfólio:

1. Exporte as imagens em JPG/PNG/WebP;
2. Copie para `assets/projetos/`;
3. Cadastre o projeto no bloco 3 (`PROJETOS`) do arquivo `js/data.js`.

O passo a passo completo está no `README.md` da pasta `portfolio/`.
